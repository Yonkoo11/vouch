What is real on this page

The block height in the header is a live call to a BSC public RPC node on every page load. Agents come from the public 8004scan API (api.8004scan.io/api/v1/agents?chain=56). That API does not currently send an Access-Control-Allow-Origin header, so a browser may refuse the cross-origin call; when that happens this page falls back to a snapshot committed in the repo and the header says so, with the timestamp it was taken. It never presents a snapshot as live. Owner and registry addresses link to BscScan so every identity claim can be checked by hand.

What is not built yet

Each card's on-chain line is measured, not claimed: transaction count, gas runway and account type come from live eth_getTransactionCount, eth_getBalance and eth_getCode calls against a BSC node when the card renders. An agent that has never sent a transaction is labelled never executed, whatever its description promises.

What is not built yet

The full performance record is the point of Vouch and it is not implemented. Realized PnL, max drawdown, revert rate and gas drag need each agent's transaction history indexed against its registered wallet, which is task 3 of the build plan and needs an indexer this static page does not have. Transaction count is a floor, not a track record. Category assignment is keyword matching over the agent name and description, not a verified capability claim. Where 8004scan has no reputation data the card says insufficient history rather than showing a zero as if it were a score. Hiring, Altana session keys, spend caps and revocation are specified in the repo and not yet wired.
