What is real on this page

The block height in the header is a live call to a BSC public RPC node on every page load. Agents come from the public 8004scan API (api.8004scan.io/api/v1/agents?chain=56). That API does not currently send an Access-Control-Allow-Origin header, so a browser may refuse the cross-origin call; when that happens this page falls back to a snapshot committed in the repo and the header says so, with the timestamp it was taken. It never presents a snapshot as live. Owner and registry addresses link to BscScan so every identity claim can be checked by hand.

What is not built yet

The performance record is the point of Vouch and it is not implemented. Where an agent has no reputation data, this page says so rather than showing a number. Realized PnL, max drawdown, revert rate and gas drag require indexing each agent's transaction history against its registered wallet, which is task 3 of the build plan. Category assignment here is keyword matching over the agent name and description, not a verified capability claim. Hiring, Altana session keys, spend caps and revocation are specified in the repo and not yet wired.
